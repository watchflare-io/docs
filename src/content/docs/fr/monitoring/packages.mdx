Sur chaque machine, l'agent recense les paquets installés et les envoie au Hub. Passage quotidien. Installé, retiré, mis à jour : tout reste dans l'historique.

---

## Comment ça se passe

**Au démarrage.** Inventaire complet, mémorisé comme référence.

**Ensuite.** Comparaison avec le fichier local. Seul le delta part : ajoutés, retirés, version changée. Même un serveur avec des milliers de paquets n'envoie presque rien.

**Quand.** 60 secondes après le lancement, puis tous les jours à **03:00** (heure de la machine).

**Sans attendre 03:00.** Onglet **Packages**, bouton **Collect now**. L'ordre part au heartbeat suivant (moins de 5 s). Dès que le scan finit, la liste se met à jour. Pratique juste après un upgrade.

<Callout type="info" title="Remarque">
  **Packages** affiche "No packages found" pendant une minute : le premier scan n'a pas encore fini. C'est normal.
</Callout>

## Mises à jour disponibles

Watchflare croise l'inventaire avec ce que le gestionnaire sait mettre à jour. Le résumé affiche deux compteurs : **outdated** et **security**.

Détection active pour :

| Gestionnaire | Commande |
|---------|--------------------------|
| apt (dpkg) | `apt-get -s upgrade` |
| dnf / yum (rpm) | `dnf check-update` |
| pacman | `checkupdates` (pacman-contrib) |
| apk | `apk list -u` |
| Homebrew | `brew outdated` |
| npm | `npm outdated -g` |
| pnpm | `pnpm outdated -g` |
| pip | `pip list --outdated` |
| gem | `gem outdated` |
| Composer | `composer outdated -g` |

Les autres (`uv`, `pipx`, `Poetry`, `Yarn`, `Cargo`, `NuGet`, `Maven`, `Nix`, `conda/mamba`, Snap, Flatpak, AppImage, MacPorts, paquets système macOS) : l'inventaire est là, `available_version` reste vide. `update_checked` dit si le gestionnaire est dans le tableau ci-dessus.

<Callout type="info" title="Remarque">
  Arch Linux : installez `pacman-contrib` (`pacman -S pacman-contrib`). Sans lui, pacman apparaît, mais Watchflare ne sait pas s'il y a des mises à jour.
</Callout>

## Historique

Chaque écart est daté, avec un type :

| Type | Signification |
|-------------|---------|
| `initial` | Déjà là au premier inventaire |
| `added` | Installé depuis le dernier passage |
| `removed` | Désinstallé depuis le dernier passage |
| `updated` | Version changée |

Onglet **History** de **Packages** : journal dans l'ordre, filtrable par type et par gestionnaire.

---

## Tout le parc

**/packages** dans la barre latérale fusionne les inventaires. Un paquet, toutes les machines : qui ne l'a pas, qui est en retard, qui a un correctif de sécurité en attente.
