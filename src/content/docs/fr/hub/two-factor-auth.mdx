Watchflare prend en charge l'**authentification à deux facteurs basée sur TOTP** (mot de passe à usage unique basé sur le temps, RFC 6238). Lorsque l'authentification est activée, la connexion exige à la fois votre mot de passe et un code à 6 chiffres provenant d'une application d'authentification.

---

## Applications prises en charge

Toute application compatible TOTP fonctionne :

- [Proton Authenticator](https://proton.me/authenticator) et [Proton Pass](https://proton.me/pass)
- [2FAS](https://2fas.com/)
- [Bitwarden Authenticator](https://bitwarden.com/products/authenticator/)
- [1Password](https://1password.com/)
- [Authy](https://authy.com/)
- Google Authenticator
- et bien d'autres !

---

## Activer le 2FA

1. Allez dans **votre nom d'utilisateur → Account**.
2. Sous **Two-Factor Authentication**, cliquez sur **Set up 2FA**.
3. Scannez le QR code avec votre application d'authentification, ou copiez la clé secrète et saisissez-la manuellement.
4. Entrez le code à 6 chiffres que votre application affiche pour confirmer la mise en place.
5. **Enregistrez vos codes de secours.** Watchflare génère 8 codes de secours à usage unique, rangez-les donc en lieu sûr. Vous pouvez les utiliser pour vous connecter si vous perdez l'accès à votre application d'authentification.

<Callout type="warn" title="Attention">
  Les codes de secours ne s'affichent qu'une fois. Si vous perdez à la fois votre application d'authentification et vos codes de secours, vous ne pouvez pas récupérer l'accès à votre compte.
</Callout>

---

## Déroulement de la connexion

Lorsque le 2FA est activé, la séquence de connexion est :

1. Entrez votre e-mail et votre mot de passe sur la page de connexion.
2. Un écran de défi 2FA s'affiche. Entrez le code à 6 chiffres de votre application d'authentification.
3. Sinon, cliquez sur **Use a backup code** et entrez l'un de vos codes enregistrés.

Le défi 2FA expire après **5 minutes**. S'il arrive à expiration, recommencez la connexion.

---

## Codes de secours

Les codes de secours sont des codes hexadécimaux de 10 caractères en majuscules (ex. `A3F7C2E1B0`). Chaque code ne peut être utilisé qu'une fois, et il est consommé à l'usage.

Vous avez 8 codes de secours après la mise en place. Pour les remplacer tous par un jeu neuf :

1. Allez dans **votre nom d'utilisateur → Account**.
2. Sous **Two-Factor Authentication**, cliquez sur **Regenerate backup codes**.
3. Entrez un code TOTP à 6 chiffres valide pour confirmer.
4. Les nouveaux codes s'affichent une seule fois, enregistrez-les donc immédiatement.

<Callout type="warn" title="Attention">
  Régénérer les codes de secours invalide tous les précédents.
</Callout>

---

## Désactiver le 2FA

1. Allez dans **votre nom d'utilisateur → Account**.
2. Sous **Two-Factor Authentication**, cliquez sur **Disable 2FA**.
3. Entrez un code TOTP à 6 chiffres valide **ou** un code de secours pour confirmer.

Après la désactivation, tous les codes de secours et le secret TOTP stocké sont définitivement supprimés.
