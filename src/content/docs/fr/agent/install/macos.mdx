**Prérequis :** macOS 11 (Big Sur) ou plus récent, Intel ou Apple Silicon, et [Homebrew](https://brew.sh).

Dans le tableau de bord : **Hosts → Add host**. Copiez le jeton d'enregistrement.

---

## Une seule commande (recommandé)

Homebrew pose l'agent, l'enrôle auprès du Hub, et démarre le service :

<CodeBlock lang="bash">
```bash
curl -sSL https://get.watchflare.io/brew | bash -s -- \
  --token wf_reg_YOUR_TOKEN \
  --host YOUR_HUB_IP \
  --port 50051
```
</CodeBlock>

Dans **Hosts**, le statut passe de **pending** à **online** en moins de 5 secondes.

<Callout type="warn" title="Attention">
  Le jeton expire au bout de 24 heures. Installez avant.
</Callout>

<Callout type="tip" title="Astuce">
  Docker Desktop ou Colima sur ce Mac ? Ajoutez `--containers` pour remonter CPU, mémoire et réseau par conteneur. Voir [Métriques Docker/Podman](/fr/agent/docker-metrics/).
</Callout>

## À la main (Homebrew)

**1. Ajouter le tap et installer**

<CodeBlock lang="bash">
```bash
brew tap watchflare-io/watchflare
brew install watchflare-agent
```
</CodeBlock>

**2. Enrôler**

<CodeBlock lang="bash">
```bash
watchflare-agent register \
  --token wf_reg_YOUR_TOKEN \
  --host YOUR_HUB_IP \
  --port 50051
```
</CodeBlock>

**3. Démarrer le service**

<CodeBlock lang="bash">
```bash
brew services start watchflare-agent
```
</CodeBlock>

---

## Service launchd

<CodeBlock lang="bash">
```bash
brew services info watchflare-agent        # état
brew services start watchflare-agent       # démarrer
brew services stop watchflare-agent        # arrêter
brew services restart watchflare-agent     # redémarrer
```
</CodeBlock>

Suivre les journaux :

<CodeBlock lang="bash">
```bash
tail -f $(brew --prefix)/var/log/watchflare-agent.log
```
</CodeBlock>

---

## Fichiers

`$(brew --prefix)` vaut `/opt/homebrew` sur Apple Silicon, `/usr/local` sur Intel.

| Chemin | Rôle |
|------|---------|
| `$(brew --prefix)/bin/watchflare-agent` | Binaire |
| `$(brew --prefix)/etc/watchflare/agent.conf` | Config (identifiants) |
| `$(brew --prefix)/etc/watchflare/ca.pem` | Certificat CA du Hub |
| `$(brew --prefix)/var/watchflare/` | Données |
| `$(brew --prefix)/var/watchflare/metrics.wal` | Journal d'écriture anticipée |
| `$(brew --prefix)/var/watchflare/packages.state.json` | État de l'inventaire des paquets |
| `$(brew --prefix)/var/log/watchflare-agent.log` | Journaux |

## Changer de Hub

Pour pointer vers un autre Hub, ou après avoir supprimé puis recréé l'hôte dans le tableau de bord :

<CodeBlock lang="bash">
```bash
brew services stop watchflare-agent
rm $(brew --prefix)/etc/watchflare/agent.conf
rm $(brew --prefix)/etc/watchflare/ca.pem
watchflare-agent register --token wf_reg_YOUR_TOKEN --host YOUR_HUB_IP
brew services start watchflare-agent
```
</CodeBlock>

## Dépannage

| Symptôme | Cause | Correctif |
|---------|-------|-----|
| `configuration error` (fichier de config introuvable) | Pas encore enrôlé | `watchflare-agent register ...` |
| `connection refused` | Mauvais hôte/port | Le port 50051 est-il joignable ? |
| `Invalid agent credentials` | Clé qui ne correspond pas | Réenrôlez l'agent |
| L'hôte reste hors ligne après le démarrage | Horloge décalée | Vérifiez l'horloge : le Hub refuse un écart de plus de ±5 min |

Journaux récents :

<CodeBlock lang="bash">
```bash
tail -50 $(brew --prefix)/var/log/watchflare-agent.log
```
</CodeBlock>

État du service :

<CodeBlock lang="bash">
```bash
brew services list | grep watchflare
```
</CodeBlock>

## Compiler sans Homebrew

Si Homebrew n'est pas possible, compilez depuis les sources (Go 1.26+). La procédure est dans le [dépôt](https://github.com/watchflare-io/watchflare). `WATCHFLARE_CONFIG_DIR` et `WATCHFLARE_DATA_DIR` indiquent où l'agent lit et écrit. Lancez-le vous-même, ou via le gestionnaire de services de votre choix.

<Callout type="info" title="Remarque">
  Un installeur macOS autonome, sans Homebrew, est prévu.
</Callout>
