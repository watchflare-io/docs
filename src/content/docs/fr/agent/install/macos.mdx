**Prérequis :** macOS 11 (Big Sur) ou plus récent, Intel ou Apple Silicon, et [Homebrew](https://brew.sh) installé.

Avant de commencer, créez l'hôte dans le tableau de bord Watchflare (**Hosts → Add host**) et copiez le jeton d'enrôlement.

---

## Installation en une commande (recommandée)

Cette commande installe l'agent via Homebrew, l'enrôle auprès du Hub et démarre le service en une seule étape :

<CodeBlock lang="bash">
```bash
curl -sSL https://get.watchflare.io/brew | bash -s -- \
  --token wf_reg_YOUR_TOKEN \
  --host YOUR_HUB_IP \
  --port 50051
```
</CodeBlock>

L'hôte passe de **pending** à **online** dans le tableau de bord dans les 5 secondes.

<Callout type="warn" title="Attention">
  Les jetons d'enrôlement expirent au bout de 24 heures. Lancez la commande d'installation avant que le jeton n'expire.
</Callout>

<Callout type="tip" title="Astuce">
  Vous faites tourner Docker Desktop ou Colima sur ce Mac ? Ajoutez `--containers` pour collecter les métriques CPU, mémoire et réseau par conteneur. Voir [Métriques de conteneurs Docker/Podman](/fr/agent/docker-metrics/).
</Callout>

## Installation manuelle

**Étape 1 : Ajouter le tap et installer**

<CodeBlock lang="bash">
```bash
brew tap watchflare-io/watchflare
brew install watchflare-agent
```
</CodeBlock>

**Étape 2 : Enrôler**

<CodeBlock lang="bash">
```bash
watchflare-agent register \
  --token wf_reg_YOUR_TOKEN \
  --host YOUR_HUB_IP \
  --port 50051
```
</CodeBlock>

**Étape 3 : Démarrer le service**

<CodeBlock lang="bash">
```bash
brew services start watchflare-agent
```
</CodeBlock>

## Gestion du service

<CodeBlock lang="bash">
```bash
brew services info watchflare-agent        # état
brew services start watchflare-agent       # démarrer
brew services stop watchflare-agent        # arrêter
brew services restart watchflare-agent     # redémarrer
```
</CodeBlock>

Suivez les journaux :

<CodeBlock lang="bash">
```bash
tail -f $(brew --prefix)/var/log/watchflare-agent.log
```
</CodeBlock>

---

## Emplacement des fichiers

`$(brew --prefix)` vaut `/opt/homebrew` sur Apple Silicon et `/usr/local` sur Intel.

| Chemin | Rôle |
|------|---------|
| `$(brew --prefix)/bin/watchflare-agent` | Binaire |
| `$(brew --prefix)/etc/watchflare/agent.conf` | Config (identifiants) |
| `$(brew --prefix)/etc/watchflare/ca.pem` | Certificat CA du Hub |
| `$(brew --prefix)/var/watchflare/` | Dossier de données |
| `$(brew --prefix)/var/watchflare/metrics.wal` | Write-Ahead Log |
| `$(brew --prefix)/var/watchflare/packages.state.json` | État de l'inventaire des paquets |
| `$(brew --prefix)/var/log/watchflare-agent.log` | Journaux |

## Réenrôler

Pour connecter l'agent à un autre Hub, ou après avoir supprimé puis recréé un hôte :

<CodeBlock lang="bash">
```bash
brew services stop watchflare-agent
rm $(brew --prefix)/etc/watchflare/agent.conf
rm $(brew --prefix)/etc/watchflare/ca.pem
watchflare-agent register --token wf_reg_YOUR_TOKEN --host YOUR_HUB_IP
brew services start watchflare-agent
```
</CodeBlock>

---

## Dépannage

| Symptôme | Cause | Correctif |
|---------|-------|-----|
| `configuration error` (fichier de config introuvable) | Pas enrôlé | Exécutez `watchflare-agent register ...` |
| `connection refused` | Mauvais hôte/port | Vérifiez que le port 50051 est joignable |
| `Invalid agent credentials` | Clé qui ne correspond pas | Réenrôlez l'agent |
| L'hôte reste offline après le démarrage | Horloge désynchronisée | Vérifiez l'horloge système, car le Hub refuse les horodatages décalés de ±5 min |

Consultez les journaux récents :

<CodeBlock lang="bash">
```bash
tail -50 $(brew --prefix)/var/log/watchflare-agent.log
```
</CodeBlock>

Vérifiez l'état du service :

<CodeBlock lang="bash">
```bash
brew services list | grep watchflare
```
</CodeBlock>

## Installer sans Homebrew

Si vous ne pouvez pas utiliser Homebrew, l'agent peut être compilé depuis les sources. Go 1.26+ est requis. Consultez le [dépôt source](https://github.com/watchflare-io/watchflare) pour les instructions de compilation. Utilisez les variables d'environnement `WATCHFLARE_CONFIG_DIR` et `WATCHFLARE_DATA_DIR` pour pointer l'agent vers des chemins personnalisés, et lancez-le à la main ou avec votre propre gestionnaire de services.

<Callout type="info" title="Remarque">
  Un installeur macOS autonome (sans dépendance Homebrew) est prévu pour une version ultérieure.
</Callout>
