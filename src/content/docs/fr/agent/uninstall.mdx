## Linux

`uninstall` pose des questions. Il arrête le service, le retire, supprime le binaire, puis demande un par un : données, config, journal, utilisateur système.

<CodeBlock lang="bash">
```bash
sudo watchflare-agent uninstall
```
</CodeBlock>

```

[1/6] Checking permissions...
  → Running as root

[2/6] Removing service...
  → Removed systemd service

[3/6] Removing binary...
  → Removed /usr/local/bin/watchflare-agent

[4/6] Data and configuration...
Remove data directory (/var/lib/watchflare)? (y/N): y
Remove configuration directory (/etc/watchflare)? (y/N): y
  → Removed /var/lib/watchflare
  → Removed /etc/watchflare

[5/6] Log files...
Remove log file (/var/log/watchflare-agent.log)? (y/N): y
  → Removed /var/log/watchflare-agent.log

[6/6] System user...
Remove system user 'watchflare'? (y/N): y
  → Removed user 'watchflare'

=== Uninstallation Complete ===
```

**Ce que contrôle chaque question :**

| Question | Ce qui part | Répondre N pour… |
|--------|----------------|--------------|
| Dossier de données | WAL, état des paquets | Garder le journal de métriques |
| Dossier de config | `agent.conf`, `ca.pem` | Garder les identifiants d'enrôlement |
| Fichier de journal | `/var/log/watchflare-agent.log` | Garder les journaux pour dépanner |
| Utilisateur système | utilisateur `watchflare` | Le garder si vous réinstallez bientôt |

**N** sur la config : `agent.conf` et `ca.pem` restent. Réinstallez plus tard avec le même `agent_id` / `agent_key` : l'agent se reconnecte, sans nouveau jeton.

<Callout type="info" title="Remarque">
  Désinstaller l'agent ne retire pas l'hôte du Hub. Il passe hors ligne sur [Hosts](/fr/monitoring/hosts/). Supprimez-le dans le tableau de bord si vous n'en avez plus besoin.
</Callout>

### Vérifier sous Linux

Rien ne doit rester :

<CodeBlock lang="bash">
```bash
which watchflare-agent           # ne doit rien renvoyer
ls /etc/watchflare 2>/dev/null   # ne doit pas exister (si vous avez répondu Y)
ls /var/lib/watchflare 2>/dev/null
systemctl status watchflare-agent 2>/dev/null
```
</CodeBlock>

## macOS

Arrêtez le service, puis retirez le paquet Homebrew :

<CodeBlock lang="bash">
```bash
brew services stop watchflare-agent
brew uninstall watchflare-agent
```
</CodeBlock>

Pour retirer aussi config et données :

<CodeBlock lang="bash">
```bash
rm -rf $(brew --prefix)/etc/watchflare
rm -rf $(brew --prefix)/var/watchflare
rm -f  $(brew --prefix)/var/log/watchflare-agent.log
```
</CodeBlock>

### Vérifier sous macOS

<CodeBlock lang="bash">
```bash
which watchflare-agent                              # ne doit rien renvoyer
ls $(brew --prefix)/etc/watchflare 2>/dev/null     # ne doit pas exister
brew services list | grep watchflare               # ne doit rien renvoyer
```
</CodeBlock>

## Retirer l'hôte du tableau de bord

Retirer l'agent ne retire pas l'hôte du Hub. Pour le supprimer :

1. Ouvrez la page de l'hôte.
2. Menu **⋯** → **Delete host**.

Ça purge l'historique de métriques, l'inventaire de paquets et les règles d'alerte.

---

## Réinstaller sans réenrôler

Pour remettre l'agent sur la même machine, sans nouveau jeton :

1. Répondez **N** à toutes les questions (Linux), ou ne lancez pas les `rm -rf` (macOS).
2. Réinstallez le binaire.
3. L'agent reprend `agent_id`, `agent_key` et `ca.pem` : il se reconnecte tout seul.

Si le dossier de config a été effacé, créez un nouvel hôte dans le tableau de bord et relancez `register` avec un jeton neuf.
